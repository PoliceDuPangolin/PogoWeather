À propos de PogoWeather

PogoWeather est un projet fan-made conçu pour aider les joueurs Pokémon GO à repérer rapidement des villes où certains Pokémon peuvent être boostés météo.

Le site fonctionne sans compte. Les villes personnalisées restent dans le navigateur de l’utilisateur. La logique de calcul principale est exécutée côté serveur afin d’éviter d’exposer toute la méthode dans le JavaScript public.
