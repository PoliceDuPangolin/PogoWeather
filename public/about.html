About PogoWeather

PogoWeather is a fan-made Pokémon GO weather boost tool created to help players estimate where specific Pokémon may currently be weather boosted. The goal is simple: enter a Pokémon name, understand which weather boosts it, and compare cities where that weather may be active in-game.

The project was built because Pokémon GO weather can be confusing. The game does not always match the sky outside or the weather app on your phone. Sometimes Pokémon GO shows Windy while a normal weather app shows Cloudy. Sometimes it shows Cloudy even when a forecast says only Partly Cloudy. PogoWeather tries to make these situations easier to understand by using forecast-based logic and city comparisons.

What PogoWeather does

PogoWeather identifies the types of a Pokémon, maps those types to Pokémon GO weather boost categories, then checks a list of important cities and hotspots. For each city, the tool estimates whether the correct weather is likely active and displays a confidence score.

For example, Rayquaza is Dragon and Flying, so the best weather to look for is Windy. Kyogre is Water, so the best weather is Rainy. Groudon is Ground, so Clear weather is the target. PogoWeather automates this matching process and helps players quickly find useful locations to check.

Why the tool uses forecasts

Pokémon GO weather appears to behave more like forecast-based weather than live observation-based weather. This means the game may follow an hourly forecast block or a previous forecast run rather than the exact real-time weather outside. Because of this, PogoWeather uses weather windows, wind values, precipitation, cloud cover and weather codes to estimate the likely in-game weather.

The model is not perfect, but it improves when real player observations are compared with the prediction. Windy, Fog and Cloudy are especially difficult to estimate, so feedback from different cities is valuable.

Who PogoWeather is for

PogoWeather is mainly useful for players who care about weather boosted raids, event preparation and global weather comparisons. It can help during legendary raid rotations, GO Fest, raid days and other limited-time events where finding the correct weather quickly can make a difference.
