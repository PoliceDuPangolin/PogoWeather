Planning a search

Pokémon GO Weather Boost Forecast

PogoWeather shows estimated weather windows for a selected Pokémon. Forecasts help with planning; they do not directly read the weather displayed by Pokémon GO.

Choose the mode

ModeUseNote
NowCompare current estimatesThe map is for this mode.
24hCompare upcoming hours across locationsUp to 25 locations, including defaults.
7 daysExplore one location over several daysSelect the city before searching.

Example: planning a Kyogre search

  1. Open the main tool and enter Kyogre.
  2. Choose 24h at the top and search. For a multi-day view, select 7 days and a city.
  3. Compare estimated Rainy windows and the local time displayed. Open the details to distinguish multiple windows.
  4. When you play, confirm the weather and raid availability in Pokémon GO.

Hours are not a probability of accuracy

The page groups estimated matching hours into windows. A displayed percentage describes the forecast period analyzed; it does not guarantee the in-game weather. The window boundaries are the first and last forecast hours in that estimated window.

When should I refresh?

Forecasts can change. Check ahead when planning and run a new search closer to the chosen time. Data unavailable for a city does not mean the target weather is absent.

Weather data: Open-Meteo.com, adapted by PogoWeather. Type associations: official Pokémon GO support.
