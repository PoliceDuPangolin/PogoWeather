Contact PogoWeather

Have feedback about a weather prediction, a city result or a Pokémon GO event guide? You can contact PogoWeather to report useful observations and help improve the weather boost model.

Best way to send weather feedback

The most useful feedback is a comparison between the in-game Pokémon GO weather and the PogoWeather result. If you report an error, try to include the city, the local time, the Pokémon GO weather, the PogoWeather prediction and the debug details shown in the result card.

Suggested feedback format

City, local time, Pokémon GO weather, PogoWeather weather, current forecast details, previous forecast details and any remark about the result.

TikTok

PogoWeather can also share short examples and event updates on TikTok. You can follow PogoWeather on TikTok for short weather boost examples, GO Fest updates and Pokémon GO event tips.

What to report

  • A city where Pokémon GO weather does not match PogoWeather.
  • A GO Fest or raid event Pokémon that should be added to the guides.
  • A bug with search, map results or city coordinates.
  • A suggestion to improve the weather boost model.
