Using PogoWeather

PogoWeather: how to use it, sources and limits

PogoWeather helps Pokémon GO players find weather conditions that may suit a selected Pokémon. It is an independent tool and is not affiliated with Pokémon GO.

How to use it

  1. Search for a Pokémon in the tool.
  2. Choose the current estimate or a forecast and compare the results.
  3. Check the weather icon in Pokémon GO before relying on the result: it is an estimate.

Reading the results

The displayed weather is an estimate, not a direct reading from the game. The tool’s indicator is not a statistically verified probability. Forecasts can change and the game may show different conditions. The boost guide shows which types match each weather category.

Choosing Now, 24h or 7 days

  • Now: compare current estimates and see the results map.
  • 24h: compare forecast windows across multiple locations. Up to 25 locations are analyzed, including defaults.
  • 7 days: choose one city before searching to see an indicative daily summary.

Forecast times use the analyzed city’s local time. A window marks estimated matching hours and may change when the data refreshes.

Add a custom city

  1. In “Custom cities” on the home page, enter a name and optionally a country.
  2. Enter latitude and longitude in decimal degrees: latitude must be between −90 and 90, longitude between −180 and 180.
  3. Select “Add”, then search. You can save up to 20 cities in that browser and remove them from the same area.

In 24h mode, default cities count towards the 25-location limit, so not every custom city will necessarily be analyzed. In 7-day mode, select the city you want directly.

If a search does not return what you expect

Check the name and coordinates and search again. If a city says its data is unavailable, the site could not obtain usable data for that result; it does not mean there is no boost. Raid availability must be checked separately in the game.

Data sources

  • Weather data by Open-Meteo.com, adapted by PogoWeather to produce estimates; source and CC BY 4.0 licence.
  • PokéAPI for Pokémon data and images.
  • Official Pokémon GO support for the weather boost type chart.
  • Community Pokémon GO API for the indicative raid list, which should be checked in the game.
